# Minimal Notes — визуальный контракт (черновик для утверждения)

Эталон: `prototype.html`. Автономный HTML/CSS/JS, без сервера и CDN. Это реконструкция двух согласованных интерфейсов из чата, не точный экспорт их рендера. После проверки владельцем утверждённый HTML и скриншоты становятся базовой линией. Данные демонстрационные, сбрасываются при перезагрузке; фиксированная дата 25.11.2026 нужна для повторяемых снимков. Не переносить эти ограничения в плагин.

## Структура
- Три раздела: Календарь, Заметки, Архив; нижняя навигация, без дополнительного дашборда.
- Мобильный экран: месяц и компактные действия в верхней строке, сетка календаря, список выбранного дня/периода, нижняя навигация. На широком экране также календарь сверху, заметки ниже, в центрированной колонке. Фильтры скрыты по умолчанию, открываются кнопкой справа сверху в выпадающем меню с чекбоксами; не сдвигают сетку. Адаптация по ширине контейнера Obsidian, не только окна.
- Нет общего заголовка над календарём. Кнопка добавления расположена в заголовке списка заметок. Переключатель темы в HTML служит демонстрации; в плагине наследовать тему Obsidian.
- Календарь: понедельник первым, числовые цветные счётчики по выбранным папкам, выделение дня/диапазона, переключение месяца, Сегодня. При выборе периода два нажатия, включая обратный порядок. Архив не учитывается. Переполнение счётчиков на узких экранах решать без горизонтальной прокрутки; видимость всех значений обеспечить раскрытием. Конкретный вид переполнения согласовать.
- Карточка: спокойная поверхность, вертикальная полоса цвета папки, название, метаданные, шеврон, отдельное действие архивации. Клик по карточке открывает заметку целиком.
- Редактор: единый текстовый ввод, первая непустая строка — заголовок, без отдельного поля. Редактор занимает всю доступную страницу; сверху только назад, параметры и готово. Папка, даты, создание папки и архив скрыты в панели параметров, открываемой одной иконкой. На мобильном панель снизу, закрытие возвращает к тексту без потери ввода. Три режима: без даты / дата / период. Создание папки через компактную кнопку. Сохранение и возврат без потери текста. HTML демонстрирует plain text; в плагине сохранить Markdown и штатные возможности, исследовать публичный API. Автосохранение в реальном плагине обязательно; в прототипе сохранение при возврате/«Готово».
- Период включителен, одна заметка отображается на каждом дне, в списке диапазона единожды. Заметки без даты в общем списке. Архивирование через метаданные, восстановление без перемещения файла.

## Токены
Акцент #9275CA; пример цветов папок #6695DE, #68A98A, #CE9B56. Фон и текст нейтральные, адаптировать к CSS-переменным Obsidian. Заголовок 22 px, заголовок заметки 15–16 px, метаданные 12 px, первая строка редактора 26 px. Базовый отступ 16 px, между карточками 8 px, скругление 8–12 px, полоска 3 px, иконки 20–24 px. Ячейка календаря 49–56 px, сенсорные цели по возможности не менее 44×44 px (для плотной сетки обеспечить доступность при узкой ширине). Без теней, градиентов, лишних рамок и декоративных виджетов. Анимации минимальные, учитывать reduced motion.

## Визуальная приёмка
- До подключения реального хранилища реализовать React UI на fixture-данных с едиными компонентами для браузера и Obsidian.
- Проверить 360×800, 390×844, 430×932, 768×1024, 1280×800, 1920×1080 и узкую панель десктопа; обе темы. Проверить реальный Android/iOS, экранную клавиатуру и safe areas.
- Сценарии: календарь с закрытым и открытым фильтром; пустой день; выбор диапазона; общий список и поиск; открытая заметка; новый редактор в трёх режимах дат; создание папки; архив и восстановление.
- Снимки Playwright с фиксированными датой, данными, темой и viewport; закрепить после одобрения владельцем. Не обновлять эталоны автоматически. Сравнение с HTML — визуальное, не требовать идентичности браузерных пикселей между платформами. После утверждения React снимков применять visual regression.
- Не менять структуру, палитру, плотность и навигацию без согласования. При конфликте с доступностью или публичным API Obsidian представить варианты владельцу, не обходить через приватные API.
- Сохранить скриншоты исходного чата в `references/` как дополнительный первичный ориентир, если доступны. Снимки в комплекте являются реконструкцией HTML, не скриншотами чата.

## Уточнения v3 (приоритет над предыдущими версиями)
- Первая строка единого редактора сразу жирная и крупная (26 px), начиная со второй — обычный текст 16 px. Enter не продолжает стиль заголовка; не добавлять отдельное поле.
- В параметрах заметки папки представлены компактным списком с цветными точками и отметкой выбора; цвета совпадают с календарём и карточками. Создание папки с выбором цвета; возможность изменить цвет существующей папки.
- Над текстом существующей заметки — ненавязчивая дата и время последнего изменения, 12 px, muted. Использовать файловое mtime, не дату календарной привязки. Просмотр без изменения не обновляет время.
- Общий список и архив группируются по дате последнего изменения (Сегодня, Вчера, далее даты), сортировка от новых к старым. Под названием — приглушённая дата изменения, отдельно от календарной привязки.
- Календарь сверху, фильтр справа, чистый лист и скрытая панель параметров сохраняются.
